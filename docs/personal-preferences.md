# Optional personal preferences

Free and Pro both offer **Personalize → About you & remembered corrections**. You can skip this and create your preview immediately. Your publication's owner and administrators can see and manage these shared preferences.

Enable the option, then choose an explanation style and level of detail. Your selected length and source checks still apply. The optional background field stays in this panel unless you explicitly share it with a local coding agent. It does not choose your news topics or provide source facts.

When something goes wrong, choose **Point out a mistake**. Pick the correction category and inspect its reminder. An extra note is optional. The harness remembers the displayed reminder for new editions; it does not turn your note into model instructions, train the model or mark a failed output as correct. You can forget a correction, disable preferences, or delete the saved profile.

**What will the writer remember?** shows the exact active guidance. It contains fixed style and review reminders, never your biography or raw mistake notes. Small-model context limits still apply; reminders can be omitted if complete evidence fills the prompt. Changing guidance requires a new edition. Existing drafts retain their original settings and evidence.

**Share with my coding agents** is optional and available to the owner on a local installation. Review the profile and choose Claude Code, Codex or the listed other-agent target. Sharing changes only the marked profile block in that agent's global instructions. The harness never imports the rest of those files. The chooser identifies an existing profile from another publication before replacement. Restart the selected agent to read the new profile. Later edits are not shared automatically.

To delete all current copies, remove selected shared copies first, then delete your saved preferences. Deletion removes this profile's local export as well. Existing edition evidence and external backups remain separate. An unsafe or changed file stops the operation with an explanation.

These are optional application preferences. Brand and presentation customization remains a separate planned Pro feature. Hosted generation, mobile store apps, Telegram/WhatsApp connections and end-to-end multilingual output are not included as completed features in this Free evaluation package.
